Chau Tieu · Blog design system · v0.1 draft

Monochrome is the structure.
Colour is the annotation.

Apple’s precision, the typography of an academic journal, an old-money palette. One sans-serif family, one reading column, and three muted accents for topics, and a fuller palette kept for code and figures.

01 — Principles

One column, generous margins

A 680 px reading measure with a quiet margin for sidenotes. Whitespace does the work that boxes and shadows usually do.

Precision over decoration

Hairline rules, aligned numbers, consistent rhythm. No gradients, no glass, no stock imagery, no emoji.

Colour carries meaning

Page chrome stays monochrome, one accent per topic. Inside code and figures a fuller palette encodes information, and each colour always means the same kind of thing.

Kinds of figure

  • Flowchart — process and data flow (Mermaid)
  • Sequence — who calls whom, in order (Mermaid)
  • C4 context / container — system structure (Mermaid C4 or D2)
  • Screenshot — real UI in a quiet window frame, metadata stripped

Rules

  • Colour encodes a category, never decoration; the legend says which.
  • Rendered to SVG at build time: follows light and dark mode, ships no diagram JavaScript.
  • Every figure has a numbered caption; text in shapes stays at 4.5:1 or better.
  • Wide figures break out to the full 956 px measure.
