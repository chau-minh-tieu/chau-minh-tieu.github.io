# Deep dives

Questions from a review that deserve a longer answer than the feature's timebox allows (HANDOFF.md 2.5). The feature's Q&A log gets the short answer and a link here; this page gets the long one when there is time for it.

## How to add one

Copy the template, newest entry first. Keep the short answer short: it is what the Q&A log already says.

```markdown
### <The question, as asked>

- **Came up in:** F<N>, <where: the review of PR #<N>, a debrief section>
- **Short answer:** <one or two sentences>
- **Why it was parked:** <what a full answer needs: reading, a spike, a measurement>
- **Sources:** <official documentation, specifications, the code>

<The long answer, when it is written: mental model first, then how it applies here, with paths.>
```
